# Baby Bites Planner

Bouw een visueel aantrekkelijke poster voor mij obv. de schema's in de PDF over babyvoeding, ik geef je ook een huisstijl mee zodat je die kan gebruiken. Het moet een soort mealplanner zijn, waarin je dag voor dag ziet welk babyhapje, hoeveel en welke allergenen er aangeboden moeten worden. Stel me eerst vragen voordat je begint met bouwen. De stijl mag fris, modern, niet truttig.
